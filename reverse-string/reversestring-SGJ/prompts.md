**Gemini**

Crear una página web que:

- Invierta el orden de una cadena de texto: El usuario ingresará un texto en un campo de entrada y al hacer clic en un botón, se mostrará el texto invertido en otro elemento de la página.
- Valide texto vacío: Si el usuario intenta invertir una cadena vacía, se mostrará un mensaje de error indicando que se debe ingresar texto.
- Permita copiar el resultado: Una vez que el texto esté invertido, se incluirá un botón para copiar el resultado al portapapeles del usuario.

La página debe incluir:

- Un campo de entrada: Para que el usuario ingrese el texto a invertir.
- Un botón para invertir: Al hacer clic en este botón, se ejecutará la función de inversión y se actualizará la página.
- Un elemento para mostrar el resultado: Donde se mostrará el texto invertido.
- Un botón para copiar: Para copiar el resultado al portapapeles.

La lógica en JavaScript debe:

- Invertir la cadena: Utilizar un método o algoritmo eficiente para invertir el orden de los caracteres de la cadena.
- Validar el texto: Verificar si el campo de entrada está vacío antes de intentar invertir la cadena.
- Copiar al portapapeles: Utilizar la API del navegador para copiar el texto al portapapeles del usuario.

Consideraciones adicionales:

- Diseño: La página debe tener un diseño simple y claro, facilitando la interacción del usuario.
- Experiencia de usuario: Se deben incluir mensajes de error claros y concisos, así como retroalimentación visual para indicar al usuario cuándo se ha copiado el texto al portapapeles.
